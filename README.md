# Assignment 6

## Description
This project was created for Web Technologies Assignment 6. It demonstrates basic jQuery selectors, effects, DOM manipulation, and animations.

## Technologies Used
- HTML
- CSS
- JavaScript
- jQuery 3.7.1

## Project Structure
- **index.html** - Home page with navigation.
- **part1.html** - jQuery Setup and Selectors (Tasks 0-1).
- **part2.html** - jQuery Effects (Tasks 2-4).
- **part3.html** - DOM Manipulation (Tasks 5-7).
- **part4.html** - Animations (Tasks 8-10).
- **part5.html** - Image Gallery Mini Project (Task 11).
- **style.css** - Website styling.
- **part1.js - part5.js** — jQuery functionality for each part.

## How to Run
1. Download or clone the repository.
2. Open `index.html` in a web browser.
3. Use the navigation bar to explore each part.
4. An internet connection is required to load jQuery from the CDN.

## Mini Project - Image Gallery
The image gallery uses jQuery effects to fade images in and out and enlarge them when clicked.
